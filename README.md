# AI Market Trend Analysis

This project implements an AI-based system to analyze historical market sales data,
forecast future demand, compare multiple machine learning models,
and generate actionable business insights.

## Project Track
AI for Market Trend Analysis

## Key Features
- Time-series data preprocessing
- Feature engineering (lag & rolling average)
- ML model comparison (Linear Regression, Random Forest)
- RMSE-based evaluation
- Business insights from forecasts

## Dataset
Real-world retail transaction dataset (UCI Machine Learning Repository),
aggregated to daily sales.

## How to Run
Open `notebook.ipynb` and run all cells top-to-bottom.
